# Project Title

## Recommended GitHub Title

`HybridMambaDet: Frequency-Decoupled Lightweight Mamba for Aerial Tiny Object Detection`

## Recommended GitHub Short Description

Lightweight frequency-decoupled hybrid Vision Mamba backbone for UAV and aerial tiny object detection with RetinaNet-based controlled comparisons on VisDrone, AI-TOD-v2, and DOTA-HBB.

## Recommended Chinese Display Title

面向航拍微小目标检测的频率解耦轻量 Hybrid Mamba

## Alternate English Titles

1. `HybridMambaDet: Lightweight Frequency-Decoupled Vision Mamba for UAV Small-Object Detection`
2. `HybridMambaDet: A Lightweight Frequency-Decoupled Mamba Backbone for Aerial Tiny Detection`

## Naming Guidance

- Use `HybridMambaDet` as the repository-facing project name.
- Use the longer title in GitHub, slides, and release notes.
- Keep the manuscript title close to the GitHub title unless the paper later needs a more formal venue-specific wording.
