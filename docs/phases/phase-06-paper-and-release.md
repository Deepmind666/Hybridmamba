# Phase 06: Paper And GitHub Release

## Goal

Turn the finished experiments into a clean English manuscript and a clear GitHub-facing repository.

## Inputs

- artifact-backed tables
- finalized figures
- verified references

## Tasks

1. Fill `paper/sections/` with artifact-backed text and citations.
2. Replace placeholder references with verified BibTeX entries.
3. Run citation audit before adding any new paper entry.
4. Keep main text scoped to backbone-level contribution only.
5. Export final paper tables into `paper/tables/`.
6. Move GitHub-facing usage instructions into `README.md`.
7. Add release notes, environment notes, and quick-start commands once the baseline is reproducible.

## Outputs

- BMVC-style manuscript draft
- clean GitHub landing page
- reproducible repository navigation

## Risks

- manuscript overclaims relative to AP_S evidence
- GitHub README diverges from actual repo layout

## Exit Criteria

- manuscript compiles
- README matches real paths and scripts
- all public-facing claims can be traced to code, artifacts, or citations
