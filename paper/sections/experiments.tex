\section{Experiments}

\subsection{Datasets}

The main evidence comes from VisDrone and AI-TOD-v2. DOTA-v1.0 is converted to HBB and used only as supplemental cross-domain evidence.

\subsection{Protocol}

All primary experiments use RetinaNet + FPN with aligned schedules, image scales, and evaluation settings. Detector heads, losses, and label assignment remain unchanged across backbone comparisons.

\subsection{Metrics}

We report AP, AP$_S$, parameter count, FLOPs, and throughput. AP$_S$ is the most important metric for validating the project hypothesis.
